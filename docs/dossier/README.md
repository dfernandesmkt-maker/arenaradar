# Dossier — Arena Radar

Fonte única de verdade para direção, IT e compliance. Cada público lê a sua pasta; nada se duplica entre elas. Os documentos Word/PDF para cada reunião são gerados a partir daqui.

| Pasta | Público | Conteúdo |
|---|---|---|
| `00-visao-geral` | Todos | Uma página: âmbito, estado e pedido |
| `01-negocio` | Direção | Caso de negócio, piloto, critérios de sucesso, custos |
| `02-tecnico` | IT | Arquitetura, fluxo de dados, ambientes e acessos |
| `03-governacao` | Compliance | Registo de dados, fontes, supervisão humana, fornecedores, riscos |
| `04-registos` | Todos | Perguntas em aberto, decisões, alterações |

## Convenções
- Cada documento começa com: **Responsável · Estado · Última atualização**.
- Estados permitidos: `Por preencher` · `Rascunho` · `Por confirmar` · `Confirmado` · `Bloqueado`.
- Nunca declarar como confirmado o que não foi validado pela entidade responsável (IT, Compliance, cliente).
- O âmbito do produto ainda está em definição. Não descrever funcionalidades como fechadas.
- Os documentos em `docs/00` a `docs/06` serão migrados para esta estrutura (tarefa RB-30 do backlog).
